Auto-create Groups
Fills the empty slots of the chosen group with 3 DPS + 1 Support per party. Characters you already placed on the raid pages stay where they are, so pin the ones you want first. Serca and Cathedral only use characters set to Party 2. A class never appears twice in the same party. The minimum ilvl follows each raid's difficulty (NM / HM / NiM). NiM has priority over HM, HM over NM. If a group cannot be completed, it still gets every eligible character that is left. With Balance combat power on, characters placed by this run are swapped between the parties of the same difficulty (NiM, HM and NM each on their own) until their combat power is as even as possible; priority and all other rules stay untouched.
